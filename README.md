# Amany dan Dio

Buat sebuah **website digital wedding invitation bertema Jawa yang sangat immersive, elegan, romantis, dan penuh animasi**, dengan pengalaman pengguna yang terinspirasi dari digital wedding invitation premium seperti:

https://waktutemu.id/dep-yase

**Jangan menyalin desain, kode, gambar, ilustrasi, atau aset dari website referensi.**

Gunakan referensi hanya sebagai inspirasi untuk:

* alur invitation
* cinematic opening
* penggunaan animasi
* transisi antar-section
* storytelling
* immersive scrolling
* penggunaan ornamen dekoratif
* pengalaman membuka undangan

Tema utama website:

# "JAVANESE ROYAL WEDDING"

Gabungkan:

**Jawa Klasik + Royal Javanese + Batik + Joglo + Wayang + Floral + Modern Web Animation**

Website harus terasa seperti membuka sebuah **undangan pernikahan Jawa premium**, bukan website biasa.
